# Agenda Odontológica — Landing page

Sitio estático (HTML + CSS puro, sin frameworks, sin build step) optimizado para:
- **Velocidad**: ~64KB de peso real de página (HTML + CSS + 2 fuentes). Sin JS de terceros, sin frameworks.
- **SEO**: meta tags, Open Graph, Twitter Card, JSON-LD (schema.org ProfessionalService), sitemap.xml, robots.txt.
- **Mobile-first**: pensado para que se vea de alto impacto en el celular antes del primer scroll (prospección desde Google Maps).

## Antes de publicar

1. Reemplaza `TUNUMERO` por tu número de WhatsApp (con indicativo, sin +, sin espacios) en `index.html`. Aparece 3 veces:
   - Botón "Agendar demostración presencial"
   - Enlace de WhatsApp en el footer
   - Botón flotante de WhatsApp
   Ejemplo: si tu número es 300 123 4567, el link queda `https://wa.me/573001234567`.

2. (Opcional) Ajusta las cifras de la sección ROI y el texto de garantía a tu política real.
